Why Is older_than Not Working in Gmail?

Updated October 2026 · 4 min read

Quick answer: When older_than does not work in Gmail, the usual cause is a search that doesn't match the documented form. Google documents older_than:1y: lowercase with an underscore, a colon, no spaces, a whole number and a unit of d, m or y. Retype it in the Gmail search box on a computer, then check any recent-looking results. Gmail can show a whole conversation when only an older message in it matches.

These are the checks to run, in order, when a Gmail age search returns nothing, too much, or the wrong mail. The syntax rules come from Google's Gmail search operators reference. If you only need the cleanup recipe, start with how to delete Gmail emails older than a year.

Which older_than variants does Gmail actually document?

Google's reference gives exactly two period examples, older_than:1y and newer_than:2d, and lists three units: d (day), m (month) and y (year). Anything else is outside the documented syntax. Gmail may still return results for it, but they may come from matching ordinary text rather than message age. The table compares common variants with the documented fix.

How do I check that my older_than search is working?

  1. Type the documented form. In Gmail on a computer, click the search box and enter older_than:1y exactly. Retype it rather than pasting from another page; pasted text can carry different characters that look the same.
  2. Cross-check with a fixed date. Run before:2025/10/17, using today's date minus one year, and compare the two result sets. They should broadly agree. Expect small differences near the boundary, because Google doesn't document exactly how the rolling cutoff is calculated.
  3. Add other conditions one at a time. Add from:sender@example.com or category:promotions, rerun the search, and only then add the next condition. If the results disappear, the last condition you added is the cause, not older_than.
  4. Widen the scope if mail seems missing. If you expect old mail in Spam or Trash, add in:anywhere, which Google documents as including Spam and Trash.
  5. Open mixed conversations before acting. Open any result that shows a recent date before you select or delete it.

Why does an older_than search show recent emails?

Google explains that Gmail "identifies matching messages first" and then shows conversations. It gives this as the reason a negative search such as -is:starred can still return a conversation that contains a starred message. The same logic applies to age. If a message from 2023 matches older_than:1y and someone replied last week, the conversation can appear in your results with last week's date. The search is working; the display is conversation-level. If you delete that conversation, the recent reply goes too, so check it first. Why doesn't older_than work in a Gmail filter?

Filters test each email as it arrives. A newly delivered email is never a year old, so an age condition in a filter has nothing to match at delivery time. Google's help says you can turn a search into a filter, but it doesn't describe filters as scheduled age-based cleanup. Run the age search by hand when you want to review old mail. Does older_than work in the Gmail mobile app?

Google's search operator reference covers Gmail on a computer and doesn't say whether the Android or iPhone apps support operators. If a search behaves unexpectedly on your phone, repeat it in Gmail on a computer before concluding the syntax is wrong.

When is a sender-wide cleanup a better fit?

Sometimes the real goal is clearing out a few heavy senders, and age doesn't matter. In that case a date search is the wrong tool. Inbox Cleaner runs in an open Gmail tab in desktop Chrome, groups senders by email count, and moves the selected senders' emails to Trash. That action covers all of a sender's mail. It does not keep your older_than cutoff, so newer mail from that sender goes too. Counts are email counts, not storage size. If the age limit matters, stay with the native search. Frequently asked questions

Does Gmail support older_than with weeks or hours?

Google's search operator reference lists only d (day), m (month) and y (year). Convert weeks to days, for example older_than:14d for two weeks.

Can I use older_than:1.5y?

Google's examples use whole numbers, so use a whole number in a smaller unit instead, such as older_than:18m.

Is older:1y the same as older_than:1y?

No. Google lists older: alongside before: as a date operator that takes a date such as 2025/10/17. older_than: takes a time period such as 1y.

Why does an older_than search show emails from this week?

Gmail matches individual messages, then shows their conversations. If an old message has a recent reply, the conversation can appear with a recent date. Open it before deleting.
