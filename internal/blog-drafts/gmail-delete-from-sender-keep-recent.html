How to Delete Emails from One Sender but Keep Recent Ones in Gmail

Updated October 2026 · 4 min read

Quick answer: To delete one sender's emails but keep the recent ones, search from:sender@example.com older_than:3m in Gmail on a computer, changing the address and the cutoff to suit you. First run the same search with newer_than:3m to see what will stay. Then open any result that shows a recent date, select the rest and move them to Trash. Gmail matches individual messages, so one conversation can hold both old and recent mail.

Gmail has no "keep the latest" button for a sender. What it does have is a search that combines the sender with an age. The work is in two places: picking a cutoff that matches what "recent" means to you, and checking conversations that cross that cutoff.

Which search matches what you want to keep?

Google's search operator reference documents from:, older_than: and newer_than: with the units d, m and y, plus before: and after: for fixed dates such as 2004/04/16. Pick the row that matches your goal. In each case the "keep" search shows what should survive, and the "delete" search is the set you trash.

How do I delete the older emails and keep the rest?

  1. Preview what you will keep. In Gmail on a computer, search from:sender@example.com newer_than:3m, with your own address and cutoff. If anything here should go too, shorten the cutoff instead of deleting by hand.
  2. Search for the older mail. Change newer_than to older_than in the same search. This is the set you will trash.
  3. Open conversations with recent dates. If a result shows a date newer than your cutoff, open it. See the next section for why this happens.
  4. Select and move to Trash. The top checkbox selects the current page only. If Gmail shows a link to select all matching conversations, click it, then click Delete. The guide to selecting all emails in Gmail explains the page-versus-all-results difference.
  5. Rerun both searches. The older_than search should come back empty, or close to it. The newer_than search should still show the mail you meant to keep.

Why can an older-mail search still show a recent email?

Google's reference says that Gmail identifies matching messages first. In conversation view, a thread whose first email is a year old can appear in an older_than:1y search even if the sender replied yesterday. Google's deletion help describes deleting from the list for whole selections, and a separate "Delete this message" option inside an open conversation. So treat a list selection as acting on the conversation you see, and remove single messages from inside the conversation when a thread mixes old and new.

If many of this sender's threads mix old and new mail, Google's conversation view help explains how to turn grouping off on a computer: Settings, See all settings, Conversation View, then Save Changes. With it off, each email shows separately. This changes how your whole inbox looks, so turn it back on afterwards if you prefer threads. We haven't tested in a live mailbox whether this changes which messages a bulk Trash action covers.

Can a sender cleanup extension keep recent emails?

Not Inbox Cleaner. It runs in an open Gmail tab in desktop Chrome, ranks senders by email count, and moves all the selected senders' mail to Trash, including archived mail. It does not carry over a date, starred, category or size limit from a search you ran. So for this job, where recent mail must stay, use the native Gmail search above. The extension fits when you want a sender gone completely, such as a newsletter you no longer read. Its counts are email counts, not storage size.

If the old mail is history you might want later, rather than clutter, consider archiving instead. The Gmail archive vs delete guide explains what each one does to storage and search.

Frequently asked questions

Can a Gmail filter keep deleting a sender's old emails automatically?

Not by age. Filters act on mail as it arrives, and a new email is never older than your cutoff. Run the older_than search by hand whenever you want to clear the backlog.

Will this also remove the sender's emails from Spam and Trash?

No. Ordinary Gmail searches leave out Spam and Trash. Google documents in:anywhere as including both, so add it only if you deliberately want those folders in scope.

Can I get the trashed emails back?

Usually, yes. Google says you can recover a message from Trash within 30 days, unless you delete it forever sooner. Open Trash, select the messages and move them back to your inbox.
