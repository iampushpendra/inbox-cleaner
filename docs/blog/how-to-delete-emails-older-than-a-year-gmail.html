How to Delete Gmail Emails Older Than a Year

Updated 18 October 2026 · 3 min read

Quick answer: Search Gmail for older_than:1y, review the results, then select unwanted conversations and move them to Trash. Check mixed-age threads before deleting: a search match does not mean every message in the displayed conversation meets your cutoff. Keep mail you still need regardless of its age.

How do I review Gmail mail older than one year?

  1. On a computer, search Gmail for older_than:1y. This is a rolling age query, not a fixed calendar-year archive.
  2. Narrow the job if useful, such as from:sender@example.com older_than:1y. Review important records and mixed-age conversations.
  3. Select only the reviewed results. To select beyond the current page, use Gmail’s all-conversations notification link when available.
  4. Choose Trash. Keep the recovery period unless you have separately reviewed and deliberately chosen permanent removal.

Google documents the age syntax in its Gmail search reference and the selection/action steps in its deletion guide. For a broader age-cleanup overview, see deleting old Gmail mail.

Can I protect starred mail just by adding -is:starred?

Review conversations before deleting. Gmail can show a conversation when only some messages match your search. Google specifically cautions that a negative search such as -is:starred can return a thread containing both starred and unstarred messages. An exclusion is not a guarantee that every message in a displayed conversation is safe to remove. Read Google’s search-operator caveat.

Do not treat a starred marker, attachment exclusion or date query as a complete retention policy. If a conversation contains something you need, keep the conversation or review individual messages. Back up required records before making an irreversible choice.

Can a Gmail filter automatically remove mail when it turns one year old?

A search performed today is different from a standing incoming-mail rule. Do not use an age query in a new-mail filter as if it were a scheduled retention engine. For existing mail, run the review when needed; do not describe this extension as an unattended age-cleanup service.

What if the real goal is storage rather than age?

Old does not mean large. Compare large-message searches with the account’s storage breakdown before deleting years of correspondence. The number of matching conversations is not a quota estimate.

Can I delete mail older than a year from the Gmail app?

Yes, because Google documents that you can enter search operators directly in the Gmail app, including date ranges. `older_than:1y` uses the same syntax there, and `after:` and `before:` are the documented fallback if you would rather pin a fixed calendar date. Selecting on Android means touching and holding a message, tapping the box next to “Select all”, and then tapping Delete, with up to 50 messages selected by default and more added by scrolling to the top and tapping it again. Use Google’s Android deletion and recovery steps, and remember that a returned conversation can still contain messages the age filter excluded. Those steps cover Android; the iPhone and iPad apps have their own controls and were not reviewed here. Inbox Cleaner requires desktop Chrome.

When does sender cleanup make sense instead?

Inbox Cleaner is an option when you want to clear mail from selected senders. It runs inside an already-open Gmail tab in desktop Chrome and groups discovered senders by email count. Counts are exact for the top 250 senders when resolved, and approximate counts use a tilde (~); counts are not storage measurements.

The extension moves selected senders’ mail to Trash. It does not carry over your date, size, category or starred-mail exclusions. Stay with native Gmail when those limits matter, and check which account is open before starting. Sender selection and the Move to Trash confirmation are separate actions.

Frequently asked questions

Is older_than:1y the same as last calendar year?

No. It expresses a rolling age. Use a specific date query when the job requires a fixed calendar boundary.

Does -is:starred guarantee every starred message is protected?

No. Gmail can display mixed conversations when individual messages match a negative search. Review the thread before deleting it.

Will Inbox Cleaner keep newer mail from a selected sender?

No. Its deletion is sender-wide; the age constraint in a Gmail search is not carried into extension cleanup.
