Gmail Filters to Delete Incoming Emails Automatically

Updated October 17, 2026 · Source-reviewed guide

A Gmail filter can move future incoming mail to Trash when it matches conditions you choose. Use this only for a clearly disposable message type. A filter does not cancel a subscription, and a filter with an age condition is not a timer that waits for each message to become old.

Create a narrowly scoped incoming rule

  1. In Gmail on a computer, open search options and enter a known sender or other clear criteria.
  2. Run the search first and inspect examples, including any messages you would regret losing.
  3. Return to the criteria, choose Create filter, and select Delete it only if matching future mail should go to Trash.
  4. Review any option to apply the rule to existing matching conversations separately; that broadens the action beyond future arrivals.
  5. Find the rule under Settings → See all settings → Filters and Blocked Addresses to edit or delete it later.

Use labels or Archive when the message still has value

If a sender mixes promotional and transactional mail, a blanket sender rule is a poor boundary. Start with a label or Skip the Inbox for records you still need. Neither changes storage usage. Avoid broad delete rules for bank notices, account security, work records or active transactions.

Age searches are not scheduled deletion

An incoming message does not already have an age of one year when it arrives. Putting older_than:1y in a standing filter does not arrange deletion a year later. Run an age search as a separate review task if you want periodic backlog cleanup.

Check mixed conversations

Search can return a whole conversation when only some messages match. In particular, -is:starred does not guarantee protection for starred messages in a mixed thread. Open important conversations and handle individual messages when necessary.

Review Trash separately

Gmail normally allows Trash recovery for up to 30 days unless permanently removed sooner. Archive and Trash still use storage. Review before Empty Trash or Delete forever; those actions end ordinary recovery.

Keep the action limited

Sender-wide extension cleanup is a poor fit when the same sender carries records or messages you must keep. Use the focused native controls described here. Read the extension’s broader scope and limits.
