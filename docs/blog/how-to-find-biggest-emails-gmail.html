How to Find the Biggest Emails in Gmail

Updated 18 October 2026 · 3 min read

Quick answer: Use Gmail’s larger: search operator to find messages above a chosen threshold, starting with larger:20M or larger:10M. Lower the threshold if needed. This finds candidates for review; it is not a largest-first storage report or a command to delete them.

How can I find large messages before deleting anything?

  1. Start with a high Gmail threshold such as larger:20M. Read the results without selecting a deletion action.
  2. If there are few or no useful results, try larger:10M, then larger:5M.
  3. Narrow the job if needed: for example, use in:sent larger:5M to inspect sent mail.
  4. Decide which messages to keep or save before using the separate deletion workflow.

The official search-operator reference documents size and scope filters. Match the search to the question you are investigating. Use the size-deletion guide only after deciding what is safe to remove.

Does Gmail size search explain my whole storage problem?

Not by itself. Check the storage breakdown to see whether Gmail is the main contributor. Mail volume, individual message size and shared quota answer different questions. A sender with many small messages can outrank a sender with a few large attachments by count while using less storage.

For account-wide diagnosis use the storage cleanup guide. If delivery has stopped, use the mailbox-full diagnostic rather than deleting based on a result count alone.

Review conversations before deleting. Gmail can show a conversation when only some messages match your search. Google specifically cautions that a negative search such as -is:starred can return a thread containing both starred and unstarred messages. An exclusion is not a guarantee that every message in a displayed conversation is safe to remove. Read Google’s search-operator caveat.

What if I want to keep a large message?

Keep it. Age or size alone does not make mail disposable. Save required files, verify that the copies open, and consider your record-keeping needs before removing correspondence. Do not assume a Drive link is a Gmail attachment or that deleting an email also deletes a separately stored Drive file.

Can I find and review large mail on my phone?

Yes, with a caveat about what you can see. Google documents that you can enter a search operator in the Gmail app to target specific emails, including a sender, a date range or messages with attachments, so a size search such as larger:10M is a reasonable starting point there. Selecting results on Android means touching and holding a message, tapping the box next to “Select all”, and then tapping Delete; the app selects up to 50 messages by default and adds more when you scroll to the top and tap it again. Use the Android deletion and recovery steps and open a candidate message before removing it, because deciding whether a large message is worth keeping means reading it. Those steps cover Android; the iPhone and iPad apps have their own controls and were not reviewed here. Inbox Cleaner requires desktop Chrome.

When does sender cleanup make sense instead?

Inbox Cleaner is an option when you want to clear mail from selected senders. It runs inside an already-open Gmail tab in desktop Chrome and groups discovered senders by email count. Counts are exact for the top 250 senders when resolved, and approximate counts use a tilde (~); counts are not storage measurements.

The extension moves selected senders’ mail to Trash. It does not carry over your date, size, category or starred-mail exclusions. Stay with native Gmail when those limits matter, and check which account is open before starting. Sender selection and the Move to Trash confirmation are separate actions.

Frequently asked questions

Does the sender with the most messages use the most storage?

Not necessarily. Sender counts do not measure bytes. Use size searches and the account storage breakdown for storage decisions.

Does finding a large email delete it?

No. A search only returns results. Selection, moving to Trash and permanent removal are separate choices.

Should I keep lowering the threshold until everything is deleted?

No. Stop when you have answered the storage question and reviewed useful candidates. Keep messages you still need.
