Why "Select All Conversations That Match This Search" Is Not Showing in Gmail

Updated October 2026 · 4 min read

Quick answer: Gmail only shows the "Select all conversations that match this search" link on a computer, after you tick the top Select box, and only when more conversations match than fit on the current page. The Gmail app on Android, iPhone and iPad has no such link: its Select all picks up to 50 messages at a time. If you are on a computer and none of those explain it, reload Gmail and try another browser before reporting it to Google.

The link is not a permanent button. It is part of a notification Gmail shows only after a page-wide selection, worded like "All 50 conversations on this page are selected. Select all 2,000 conversations in Inbox." Google documents that flow in Delete messages in Gmail (checked 17 October 2026). If you just need the basic steps, start with how to select all emails in Gmail. This page is for when the link is not there.

Why is the select all conversations link missing?

Match what you see to the first cause that fits. They are ordered from most to least common.

  1. You're in the Gmail app, not on a computer. Google's Android and iPhone and iPad instructions say to touch and hold a message, then tap the box next to "Select all", which selects up to 50 messages. To do more, you delete, scroll back to the top and select all again. There is no match-the-whole-search link in the app.
  2. You ticked individual messages. The notification follows the top Select box above the message list. Checking messages one by one, or partly selecting the page, does not trigger it. Untick everything, then tick the top box once.
  3. Everything already fits on one page. If your search or label returns fewer conversations than your page size, the page selection is already the full set. There is nothing to extend, so Gmail has no reason to show the link. If the next-page arrow at the top right is greyed out, this is your answer.
  4. You're in a narrower view than you think. The link selects what matches the current category, label or search. In the Primary tab it covers Primary only. Google's steps start by choosing the category, such as Inbox, Promotions or All mail. Pick the right one first.
  5. You acted before clicking the link. The notification sits above the messages. If you clicked Delete or Archive straight after ticking the box, the action applied to the current page only. Scroll up, tick the box again and click the link before the action.
  6. Gmail itself is misbehaving. Reload, then try a different browser or a window with your browser extensions turned off. If the link is still missing on a multi-page search, send feedback from Gmail's Help menu. This has happened before: in October 2020 Google said the link had been removed unintentionally and that it was working to restore it.

How do I check whether there's more than one page of results?

Look at the counter at the top right of the message list, such as "1–50 of 2,000", and the arrows beside it. If the arrows are both inactive, every match is already on screen. Your page size is set under Settings → See all settings → General → Maximum page size. A larger page size makes it more likely that a small search fits on one page, which is why the link can vanish after you change that setting. That is expected, not a fault.

Is there another way to act on every matching email?

Yes. Here are the options, from most to least practical:

  • Repeat the page selection. Tick the top box, act, and repeat until the search is empty. This is slow on a big search, but it works on both a computer and the app.
  • Use a filter on existing mail. In 2020, while the link was missing, the documented workaround was to create a filter from the search, tick "Also apply filter to matching conversations", then delete the filter so it does not act on future mail. Check the search results before you save anything that deletes. Google's filter instructions cover the basic steps.
  • Narrow the job by sender. If the search you're struggling with is really "everything from these senders", working sender by sender keeps each batch small and easy to check.

Before deleting a large selection, decide whether you actually want it gone. Archiving versus deleting in Gmail explains which one keeps the mail searchable. Deleted mail sits in Trash for 30 days before Gmail removes it.

When does a sender-based tool fit instead?

If the backlog is mostly a few high-volume senders, a select-all over one huge search is not the only route. The free Inbox Cleaner Chrome extension runs inside a Gmail tab you already have open in desktop Chrome. It scans your categories and ranks senders by email count. You tick the senders, then click Move to Trash as a separate step. Senders are processed in batches of up to 20, each using Gmail's own controls. Counts are exact for the top 250 senders, and the rest show a "~".

Two limits matter here. Deleting by sender is sender-wide, so the extension cannot carry over a date, category or -is:starred condition from your Gmail search. If you need those exclusions, stay with Gmail's own selection. Frequently asked questions

Can I select all conversations in the Gmail app on my phone?

Not in one pass. Google's Android and iPhone instructions say Select all in the Gmail app selects up to 50 messages; you delete them, scroll to the top and select all again. For a larger search, use Gmail on a computer.

Has Google ever removed the select all conversations link?

Yes, briefly. In early October 2020 the link disappeared for many users, and Google said the removal was unintentional and that it was working to restore it. If it is missing for you today, check the ordinary causes in this guide before assuming another bug.

Does changing the maximum page size make the link appear?

It can make the link disappear, not appear. If your page size is large enough to show every match, the whole result set is already on the page and there is nothing extra to select. A smaller page size does not change what the link selects.

Will selecting all conversations also delete starred or important emails?

Yes, if they match the search. Add -is:starred or -is:important to the Gmail search before selecting, and remember that Gmail acts on conversations, so a thread can be returned because one of its messages matched.
