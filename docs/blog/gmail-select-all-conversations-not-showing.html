Why Gmail’s Select All Conversations Link Is Missing

Updated October 17, 2026 · Source-reviewed guide

Gmail’s all-matching-conversations link is separate from the top checkbox. It is useful when the results extend beyond the current page. If you cannot find it, first confirm that you are in Gmail on a computer and have selected the page using the top checkbox.

Diagnose the missing link

  • Have you selected the page? The notification is part of the selection state; looking at an unselected list is not enough.
  • Do all matches fit on the page? If so, there may be no additional results to select. Compare the displayed range and result count.
  • Are you in a message, a search list or a special view? Return to a normal search list and run the intended query again.
  • Are you using a mobile app? Desktop instructions do not describe every app selection control. Use Gmail on a computer for this workflow.
  • Has Gmail actually finished loading? Let the list settle and inspect its notification. If the interface remains inconsistent, stop rather than clicking an unrelated control.

Do not rely on a fixed page number

Gmail’s documentation uses an example with 50 conversations. Your page settings and results can differ. The distinction to check is this page versus all matching results, not whether a particular number appears.

Once selection is clear

  1. Open Gmail on a computer, confirm the account, and search from:sender@example.com. Replace any example sender with the address from a real message.
  2. Review several results and any mixed conversations. Save records you need before selecting mail.
  3. Use the top checkbox to select the current page. If Gmail offers an all-matching-conversations notification, use its link only after checking that the search scope is correct. The page count depends on your settings.
  4. Choose the Trash icon and wait for Gmail’s confirmation. Rerun the search to inspect what remains; do not assume an unseen batch completed.

Check mixed conversations

Search can return a whole conversation when only some messages match. In particular, -is:starred does not guarantee protection for starred messages in a mixed thread. Open important conversations and handle individual messages when necessary.

Review Trash separately

Gmail normally allows Trash recovery for up to 30 days unless permanently removed sooner. Archive and Trash still use storage. Review before Empty Trash or Delete forever; those actions end ordinary recovery.

Does sender cleanup fit this task?

Inbox Cleaner needs an open Gmail tab in desktop Chrome. Its sender-wide action can include archived mail and does not inherit date, category, size, unread or starred restrictions. For those limits, use native Gmail. Counts may be approximate and are not storage measurements. Read setup, permissions and recovery limits.
