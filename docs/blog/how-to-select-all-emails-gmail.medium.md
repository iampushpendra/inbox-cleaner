# How to Select All Emails in Gmail, Beyond One Page

Select every matching Gmail conversation on desktop, understand the current-page checkbox, and find the right steps when the select-all link is missing.

## Quick answer

On a computer, select the checkbox above Gmail’s message list, then use the notification link to extend the selection to all matching conversations. The first checkbox selects the current page; the follow-up link extends the scope. Read the view and selection notice before taking action.

## How do I select more than one page of Gmail emails?

1. Open Gmail on a computer and choose the category, label or search you intend to act on.
2. Check the selection box above the message list. This selects the current page.
3. If Gmail offers a link to select all conversations in that view or search, click it to extend selection beyond the page. Read the selection notice before proceeding.
4. Review the scope, then choose the intended action: for example, Archive, a label or Trash. Cancel the selection if the view is wrong.

Google describes this two-stage selection in its [desktop deletion instructions](https://support.google.com/mail/answer/7401?hl=en). The example uses 50 conversations on a page; that example is not a universal mailbox or deletion limit. Selecting mail also does not delete it: the action comes afterward.

## Which selection should I use?

| Your task | Start here | Scope to check |
|---|---|---|
| Clear the Inbox | Open Inbox | Inbox is not the entire account; archived mail is elsewhere. |
| Review promotional mail | Open Promotions or search `category:promotions` | A category is narrower than all mail. |
| Work on one sender | Search `from:sender@example.com` | Review mixed conversations before deleting. |
| Include Spam and Trash | Only deliberately use `in:anywhere` | This explicitly broadens the search to those folders. |

Choose the narrowest view that solves your task. Clearing the search box does not automatically select the whole account. For sender-specific instructions, see [How to Delete All Emails from One Sender in Gmail](/blog/delete-all-emails-from-one-sender-gmail.html).

## Frequently asked questions

**Does the first checkbox select every matching email?**

It selects the current page. Use Gmail’s follow-up all-conversations link, when offered, to extend selection beyond that page.

**Can I undo selecting emails?**

Selection alone does not change mail. Clear the checkbox or cancel the selection before taking an action.

**Does selecting all remove archived emails?**

Selection alone removes nothing. The current view or search determines what is selected; an Inbox-only view does not cover archived mail.
