How to Delete All Emails from One Sender in Gmail

Updated October 17, 2026 · Source-reviewed guide

To delete mail from one sender, search from:sender@example.com in Gmail on a computer. Review the results, select the current page, extend to all matching conversations if Gmail offers that link, then use Trash. Gmail’s initial page selection is not the same as the entire search result.

Use the actual address, not just a display name

Open an example message and expand its sender details. A brand can send receipts, security notices and promotions from different addresses. An exact address gives you a narrower starting point than a brand name or domain; neither a familiar name nor a domain search proves that every matching message is disposable.

  1. Open Gmail on a computer, confirm the account, and search from:sender@example.com. Replace any example sender with the address from a real message.
  2. Review several results and any mixed conversations. Save records you need before selecting mail.
  3. Use the top checkbox to select the current page. If Gmail offers an all-matching-conversations notification, use its link only after checking that the search scope is correct. The page count depends on your settings.
  4. Choose the Trash icon and wait for Gmail’s confirmation. Rerun the search to inspect what remains; do not assume an unseen batch completed.

Keep recent or important correspondence

For older mail from that sender, try from:sender@example.com older_than:1y. For inbox clutter alone, add in:inbox. Preview each result set before selecting it. Ordinary searches do not include Spam and Trash; in:anywhere expands to those folders and should be used only deliberately.

If only one page moved

Check whether you selected the page or clicked the separate all-results link. If the link is missing, check the missing-selection diagnostic. Wait for any active operation, rerun the same search and compare the remaining results before trying a narrower date range. There is no universal 50-message deletion cap.

Check mixed conversations

Search can return a whole conversation when only some messages match. In particular, -is:starred does not guarantee protection for starred messages in a mixed thread. Open important conversations and handle individual messages when necessary.

Can I delete one sender’s mail from the Gmail app on my phone?

Yes. Google’s Android instructions use a sender search as their own worked example, so searching from: that address in the app is a documented route rather than an assumption. Selecting the results means touching and holding a message, tapping the box next to “Select all”, and then tapping Delete; the app selects up to 50 messages by default and adds 50 more each time you scroll to the top and tap it again. Expect to repeat that across a large backlog, and check the selected count each round. Follow Google’s Android deletion and recovery steps rather than assuming the desktop sender controls exist. Those steps cover Android; the iPhone and iPad apps have their own controls and were not reviewed here. Inbox Cleaner requires desktop Chrome.

Does sender cleanup fit this task?

Inbox Cleaner needs an open Gmail tab in desktop Chrome. Its sender-wide action can include archived mail and does not inherit date, category, size, unread or starred restrictions. For those limits, use native Gmail. Counts may be approximate and are not storage measurements. Read setup, permissions and recovery limits.

Review Trash separately

Gmail normally allows Trash recovery for up to 30 days unless permanently removed sooner. Archive and Trash still use storage. Review before Empty Trash or Delete forever; those actions end ordinary recovery.
