How to Delete Old Emails in Gmail by Date or Age

Updated October 17, 2026 · Source-reviewed guide

Gmail supports both relative age searches and fixed date boundaries. Use older_than:1y for mail older than a year, or before:2025/01/01 for a specific cutoff. Review the results, select the intended scope and use Trash. Age alone does not establish that mail is safe to remove.

Relative age or fixed date?

  • older_than:6m uses months; older_than:2y uses years. The results change as time passes.
  • before:2025/01/01 is a fixed boundary that is easier to document and repeat.
  • after:2023/01/01 before:2024/01/01 targets a bounded period. Check emails near the boundaries if exact inclusion matters.
  • Add from:sender@example.com or category:promotions to reduce the review scope.
  1. Open Gmail on a computer, confirm the account, and search before:2025/01/01.
  2. Review several results and any mixed conversations. Save records you need before selecting mail.
  3. Use the top checkbox to select the current page. If Gmail offers an all-matching-conversations notification, use its link only after checking that the search scope is correct. The page count depends on your settings.
  4. Choose the Trash icon and wait for Gmail’s confirmation. Rerun the search to inspect what remains; do not assume an unseen batch completed.

Choose a retention boundary before deleting

Preserve correspondence needed for taxes, contracts, warranties, work policies or open disputes. There is no universal one-year or seven-year rule for email. Confirm the requirements for your records and jurisdiction. A downloaded attachment should be opened and checked before you rely on it as your only copy.

Old does not mean large

If the problem is storage rather than visual clutter, combine age with a size query such as older_than:1y larger:10M. Check Google’s storage breakdown first: other services can account for the pressure. Deleting many small messages may have a limited effect on capacity.

Do not use an age filter as a rolling timer

Gmail filters act on incoming messages. A rule containing older_than:1y does not arrange for each new message to be deleted a year later. For periodic cleanup, save the search somewhere you can rerun it and review the results each time.

Check mixed conversations

Search can return a whole conversation when only some messages match. In particular, -is:starred does not guarantee protection for starred messages in a mixed thread. Open important conversations and handle individual messages when necessary.

Does sender cleanup fit this task?

Inbox Cleaner needs an open Gmail tab in desktop Chrome. Its sender-wide action can include archived mail and does not inherit date, category, size, unread or starred restrictions. For those limits, use native Gmail. Counts may be approximate and are not storage measurements. Read setup, permissions and recovery limits.

Review Trash separately

Gmail normally allows Trash recovery for up to 30 days unless permanently removed sooner. Archive and Trash still use storage. Review before Empty Trash or Delete forever; those actions end ordinary recovery.
