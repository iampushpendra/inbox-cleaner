# How to Delete Promotional Emails in Gmail

Search `category:promotions` in Gmail on a computer to review mail Gmail classified as promotional. Select the current page, extend to all matching conversations if offered, then use Trash. Category labels are a starting point for review; they do not certify that every message is unwanted.

## Steps

1. Open Gmail on a computer, confirm the account, and search `category:promotions`.
2. Review several results and any mixed conversations. Save records you need before selecting mail.
3. Use the top checkbox to select the current page. If Gmail offers an all-matching-conversations notification, use its link only after checking that the search scope is correct. The page count depends on your settings.
4. Choose the Trash icon and wait for Gmail’s confirmation. Rerun the search to inspect what remains; do not assume an unseen batch completed.

## Narrow the cleanup instead of deleting every promotion

Try `category:promotions older_than:6m` for an older backlog, or add `from:sender@example.com` for one subscription. The age cutoff is your choice, not a rule about what is safe to delete. Review order receipts, memberships and messages you may need for a return or dispute.

## Why Promotions can look empty or incomplete

An inbox tab displays a particular view; a search examines the category. Inbox configuration, custom labels and Gmail’s classification can affect what you see. Mail from the same sender can appear in other categories, and a Promotions search is not a complete list of all marketing messages. If selection stops at the visible page, follow [the two-stage selection steps](/blog/how-to-select-all-emails-gmail.html).

## Stop future promotional mail separately

Deleting old promotions does not tell a sender to stop. Use Gmail’s **Manage subscriptions** view if available, or open a legitimate subscription and use Gmail’s Unsubscribe control. A sender can take several days to honor the request. Report suspicious mail as spam rather than visiting an untrusted unsubscribe page.

## Check mixed conversations

Search can return a whole conversation when only some messages match. In particular, `-is:starred` does not guarantee protection for starred messages in a mixed thread. Open important conversations and handle individual messages when necessary.

## Does sender cleanup fit this task?

Inbox Cleaner needs an open Gmail tab in desktop Chrome. Its sender-wide action can include archived mail and does not inherit date, category, size, unread or starred restrictions. For those limits, use native Gmail. Counts may be approximate and are not storage measurements. [Read setup, permissions and recovery limits](/blog/inbox-cleaner-setup-permissions-recovery.html).

A Promotions badge in the extension is useful for discovery, but selecting that sender is a sender-wide cleanup. It is not a promise that only promotional mail will move. Use the category search above when that boundary matters.

## Review Trash separately

Gmail normally allows Trash recovery for up to 30 days unless permanently removed sooner. Archive and Trash still use storage. Review before Empty Trash or Delete forever; those actions end ordinary recovery.
