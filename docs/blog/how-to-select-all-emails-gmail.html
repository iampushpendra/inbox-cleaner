How to Select All Emails in Gmail, Beyond One Page

Updated 17 October 2026 · 4 min read

Quick answer: On a computer, select the checkbox above Gmail’s message list, then use the notification link to extend the selection to all matching conversations. The first checkbox selects the current page; the follow-up link extends the scope. Read the view and selection notice before taking action.

How do I select more than one page of Gmail emails?

  1. Open Gmail on a computer and choose the category, label or search you intend to act on.
  2. Check the selection box above the message list. This selects the current page.
  3. If Gmail offers a link to select all conversations in that view or search, click it to extend selection beyond the page. Read the selection notice before proceeding.
  4. Review the scope, then choose the intended action: for example, Archive, a label or Trash. Cancel the selection if the view is wrong.

Google describes this two-stage selection in its desktop deletion instructions. The example uses 50 conversations on a page; that example is not a universal mailbox or deletion limit. Selecting mail also does not delete it: the action comes afterward.

Review conversations before deleting. Gmail can show a conversation when only some messages match your search. Google specifically cautions that a negative search such as -is:starred can return a thread containing both starred and unstarred messages. An exclusion is not a guarantee that every message in a displayed conversation is safe to remove. Read Google’s search-operator caveat.

Why is the all-conversations link missing?

First confirm that you selected the checkbox above the list rather than a single row. Then read the notice above the messages. If the entire result set fits on the selected page, there is no larger result set to select. Check whether you are in a phone app: desktop instructions and app controls differ.

For a focused diagnostic, use the missing select-all link guide. A missing link alone does not prove an account restriction or a Gmail outage. If a bulk action seems incomplete, inspect the results before retrying rather than repeatedly issuing the same action.

Can I select multiple emails in the Gmail phone app?

Yes. Google’s Android instructions describe holding a message and using Select all, initially selecting up to 50 messages with a way to add more. Do not assume a desktop all-results notification is present in the app. Check the app’s selected count, and use a computer for the desktop workflow. Inbox Cleaner requires desktop Chrome.

When does sender cleanup make sense instead?

Inbox Cleaner is an option when you want to clear mail from selected senders. It runs inside an already-open Gmail tab in desktop Chrome and groups discovered senders by email count. Counts are exact for the top 250 senders when resolved, and approximate counts use a tilde (~); counts are not storage measurements.

The extension moves selected senders’ mail to Trash. It does not carry over your date, size, category or starred-mail exclusions. Stay with native Gmail when those limits matter, and check which account is open before starting. Sender selection and the Move to Trash confirmation are separate actions.

Frequently asked questions

Does the first checkbox select every matching email?

It selects the current page. Use Gmail’s follow-up all-conversations link, when offered, to extend selection beyond that page.

Can I undo selecting emails?

Selection alone does not change mail. Clear the checkbox or cancel the selection before taking an action.

Does selecting all remove archived emails?

Selection alone removes nothing. The current view or search determines what is selected; an Inbox-only view does not cover archived mail.
