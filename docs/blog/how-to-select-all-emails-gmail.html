How to Select All Emails in Gmail

Updated 17 October 2026 · 5 min read

Quick answer: Click the checkbox above your message list to select the conversations on the current page, then click the banner that appears — "Select all conversations that match this search" — to extend the selection to everything matching your current tab or search. On very large matches that banner can stall; Inbox Cleaner takes a different approach and cleans up by sender instead.

Gmail's checkbox looks like it should select your whole inbox in one click. It doesn't — it only grabs what's rendered on the current page, which is 50 conversations at Gmail's default page size. Most people click it, see 50 emails highlighted, and assume that's everything. It usually isn't. Here's how selection actually works in Gmail, and what to do once you hit its limits.

How do I select all emails in Gmail?

  1. Open the inbox, label, or search results you want to work from.
  2. Click the checkbox in the top-left corner of the message list, above the first email. This selects every conversation visible on the page — up to 50.
  3. A blue banner appears above the list: "Select all conversations that match this search." Click it.
  4. Gmail now selects every matching conversation, not just the visible 50 — the count updates to show the real total.
  5. Click Trash, Archive, or a label icon to apply your action to the entire selection at once.

That banner is the part most people miss. Without clicking it, any bulk action — delete, archive, mark as read — only touches the page you're looking at, and you'll be back on page two doing it again a minute later, the same wall you'd hit trying to bulk delete Gmail emails any other way.

Why does the checkbox only select the current page?

Gmail paginates its message list — 50 conversations is the page size Google's own help page uses in its example — so the checkbox can only select what your browser has actually rendered. That is a rendering limit, not a limit on how much you can delete, which is exactly why the follow-up banner exists as a separate step: it runs the action against Gmail's servers rather than against the loaded page.

What if select-all times out on a huge inbox?

On inboxes with tens of thousands of emails built up over years, the "select all conversations that match this search" action can stall or fail partway through — Gmail applies the action to every match server-side, and very large batches sometimes exceed what the web interface handles reliably in one pass.   3. It scans all five Gmail categories and ranks discovered senders by email count. A full scan takes minutes, not seconds. Counts are exact for the top 250 senders and shown with a "~" for the rest.

Scope note: deleting by sender reaches everything Gmail returns for that address, including archived mail and other labels — not just what's in your Primary inbox. How do I select emails from just one sender or date range?

Narrow the view before you select. Type from:sender@example.com in Gmail's search bar to filter to one sender, or combine date operators like before:2024/01/01 to grab everything older than a cutoff. Once the search results load, the checkbox and "select all conversations that match this search" banner both apply only to that filtered set — so you can safely bulk-delete a single newsletter's backlog without touching anything else in your inbox. This is effectively how you'd delete all emails from one sender in Gmail without the tool.

Why didn't the "select all conversations that match this search" banner appear?

This is the single most common reason people believe Gmail is stuck at one page. The banner does not appear on its own — Gmail shows it only after the page checkbox has been clicked. Work through these in order:

  1. You didn't click the top checkbox first. The banner is a follow-up to a page selection. Click the checkbox above the first email, then look immediately above the list.
  2. You're looking in the wrong place. Gmail shows it as a notification above your messages, and its wording includes the real totals — something like "All 50 conversations on this page are selected. Select all 2,000 conversations in Inbox." Scroll up so that line is on screen.
  3. The page was already fully selected. If the page count equals the highlighted count, there's nothing to extend and the banner is correctly absent.

Google's own documentation describes exactly this two-step flow, including the 50-per-page notification and the link that extends selection to every matching conversation. Delete messages in Gmail (verified 17 October 2026)

Note the search box matters too: the banner extends to everything matching the current search, not your whole mailbox. In the Primary tab with no search it covers Primary. Clear filters, or search in:anywhere, before you rely on it.

Does select all work the same way in every Gmail tab?

Yes, but it's scoped to whatever tab or search you're currently viewing. Selecting all in the Promotions tab only selects Promotions emails; switch to Primary or Social first if you want those instead. The same applies to labels — selecting all in a label only grabs conversations with that label, not your whole inbox. If you want a true inbox-wide selection, search in:anywhere or clear all filters before you start.

Frequently asked questions

Why does Gmail only select 50 emails when I click the checkbox?

Because 50 is Gmail's page size, not a deletion limit. The checkbox selects only what the browser has rendered; the "select all conversations that match this search" link then applies your action to every match server-side. Google's help page shows this as "All 50 conversations on this page are selected. Select all 2,000 conversations in Inbox."

Is there a keyboard shortcut to select all emails in Gmail?

Yes. With keyboard shortcuts enabled in Gmail settings, press * then A to select all conversations on the current page. It has the same 50-email limit as clicking the checkbox — you still need the follow-up banner to extend it further.

Why did Gmail's select-all banner not appear?

The banner only appears after you click the top checkbox to select the current page. If it doesn't show up, scroll back to the top of the message list — Gmail renders it as a notification above the messages, usually worded like "All 50 conversations on this page are selected. Select all 2,000 conversations in Inbox." If the page is already entirely selected, there's nothing to extend and the banner is correctly absent.

Can I select all emails from a specific sender or date range?

Yes. Search for from:sender@example.com or use a date operator like before:2024/01/01 in Gmail's search bar first, then use the checkbox and select-all banner on the filtered results. The selection only applies to whatever your search returned.

Does select all conversations that match this search include emails in other tabs?

No. It only selects conversations matching your current view — if you're in the Promotions tab, it selects Promotions only. Switch tabs or broaden your search first if you want to select across your whole inbox.
