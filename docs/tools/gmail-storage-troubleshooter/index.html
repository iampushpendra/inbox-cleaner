Start with the right number

Inbox message count is not storage usage. Archiving clears the inbox view but keeps mail in your account. A few large attachments can matter more than many small messages.

Gmail shares Google storage with Drive, Photos and other counted data. Check the total and the account before deciding what to remove.

Review before you remove

Gmail Trash is a recovery window

Normal Gmail deletion moves messages to Trash for up to 30 days. Trash and Spam still use storage. Review and restore needed messages before permanent deletion; Delete forever removes the recovery option.

Understand permanent deletion →

Google One uses a different flow

The storage manager offers cleanup across services. Its Gmail and Drive deletion flow can permanently delete selected items; Photos uses Move to trash. Read the exact confirmation and keep needed copies first.

Review Google One cleanup options →

Choose cleanup that fits

For space, start by reviewing large Gmail messages. If your goal is removing unwanted senders, sender-wide cleanup may help. Inbox Cleaner for Chrome ranks senders by count and moves selected senders’ mail to Trash; it does not measure bytes or free quota immediately.

Still blocked? See Gmail can’t receive mail, the storage-full guide, or cleanup versus more storage. If Google’s meter shows space, follow Google’s missing-mail troubleshooting instead of assuming more deletion will fix delivery.
